# Tickets et mini-specs

Un fichier par tâche de la fiche : `T<numéro>-<résumé>.md`, par exemple `T07-pied-droit.md`.
Ils sont versionnés : ils montrent ta méthode à l'exposé.

## Modèle

```markdown
# T07 — Poses et levers du pied droit
- Mode : APPRENDRE | PRODUIRE
- Départ : ce qui existe avant la tâche
- Action : ce qui doit changer
- Résultat attendu : comportement observable, avec des valeurs
- Vérification : commande (`make test-one F=...`) et critère de la fiche (CA…)
- Hors périmètre : ce qu'on ne fait pas ici
- Décisions : choix tranchés pendant la tâche, et pourquoi
```
